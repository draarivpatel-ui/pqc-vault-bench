01 / Ring arithmetic

Number Theoretic Transform

The speed primitive inside ML-KEM. Polynomials live in Z3329[x]/(x256+1). Seven Cooley-Tukey stages plus base-case multiplication give exact negacyclic convolution, verified against an O(n2) schoolbook reference.

03 / Hash-based signatures, part one

WOTS+ one-time signer

Winternitz chains with w=16 turn a 256-bit digest into 67 short hash chains. A checksum stops an attacker from pushing any chain forward. Each key is safe for exactly one message.

04 / Hash-based signatures, part two

XMSS Merkle tree

A stateful many-time signature scheme: 2h WOTS+ public keys become leaves of a Merkle tree. Every signature carries a leaf index and an authentication path. State is consumed, never reused.

05 / Q-Day readiness

Shor, Grover & UTXO exposure

Shor breaks elliptic-curve discrete logs in polynomial time; Grover only halves hash preimage security. Whether a UTXO is exposed depends on whether its public key is already visible on chain.
